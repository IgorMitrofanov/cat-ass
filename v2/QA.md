# Проверка V2

Использован локальный `telltale-specificity`, SHA256 и происхождение записаны в `../skills/telltale-specificity/PROVENANCE.md`. Исходники V2 написаны отдельно от V1. Общие материалы: изображения Жмыха, Golos и цены. Второй персонаж удалён из текущих версий, вместо него создан подстриженный Жмых.

## Визуальная проверка

Рендеры 360, 390, 768 и 1440 px, полный лист страницы, сравнение двух версий и отдельное изображение для ссылки. В первой итерации устранены пустота перед котом на телефоне, наложение подписей и горизонтальное переполнение. Во второй поднят размер основного мобильного текста до 16 px и добавлено лицо Жмыха в логотип. В заключительной проверке подписи у лап вынесены в свободное место. Крупные заголовки, цены, подписи и кнопки прочитаны на рендерах.

## Поведение

Автоматическая проверка в изолированном Chromium подтвердила:

- Все четыре процедуры меняют портрет; каждое изображение загружается.
- Выбор даёт правильную сумму: 0 ₽ без услуг, 5 400 ₽ со всеми.
- Выбор сохраняется в URL и восстанавливается после перезагрузки. Неизвестные значения не влияют на сумму.
- Checkbox работает с клавиатуры. Результат закрывается кнопкой и Escape; фокус возвращается к кнопке.
- FAQ открывается. Уменьшение движения учитывается.
- Нет горизонтального переполнения на 360, 390, 419, 420, 599, 600, 768, 899, 900, 1024 и 1440 px.
- При ошибке загрузки картинки есть понятное сообщение; смена процедуры восстанавливает портрет.
- На странице сравнения работают обе версии, переключение видимости и ширины viewport 390/1440 px. На телефоне сначала показана V2.
- Первая версия использует новый портрет подстриженного Жмыха; старое имя отсутствует.
- Ошибок JavaScript и неудачных HTTP-запросов в штатном сценарии нет.

`npm run build` проверяет ссылки относительно каждого исходного файла и собирает обе версии. В релиз не входят исходные PNG, внутренние документы, снимки скилла и изображение удалённого второго персонажа.

## Скилл и контраст

`check_contrast.py` на светлой и тёмной системной настройке при 390/1440 px: **0 ошибок**. Поддерживается одна светлая тема. Автоматика оставила для ручной проверки подписи внутри прямоугольников прозрачных PNG; на рендерах проверены фактические участки фона и читаемость подписей.

Кандидаты `check_design_tells.py` рассмотрены:

| Кандидат | Решение |
| --- | --- |
| SVG | Оставлены для настоящих контролов, checkbox, действия и фирменных глаз; emoji не используются. |
| Русские тире | Оставлены как грамматические знаки и часть конкретных реплик Жмыха; метафоры и юмор запрошены пользователем. |
| Большие радиусы | Портретная арка, круглый кроп, рамка портрета, индикатор выбранной процедуры и круглая кнопка закрытия имеют собственную функцию. Это не скругление всех блоков. |
| `border-left` | Нейтральный разделитель колонок прайса, не цветная статусная полоса. |
| `outline:0` у input | Нативный input покрывает всю строку и прозрачен. Явный focus-ring перенесён на родительский `.service-option:has(input:focus-visible)`. |
| Empty state | Реализован и проверен: пустой выбор даёт 0 ₽ и отдельный текст результата. |
| Privacy / terms не найдены | Оба документа доступны через общую страницу `../about.html`, ссылка подписана по-русски. |

Реальное устройство iPhone не использовалось. Иконки выполнены SVG/CSS, без зависимости от шрифтовых emoji. Обновлённая версия не является измеренным доказательством превосходства скилла: это один альтернативный дизайн на том же брифе.
