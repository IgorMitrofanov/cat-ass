# Проверка релиза

30 октября 2026 года.

## Результат

Сборка `npm run build` прошла. Она проверяет локальные ссылки на изображения, шрифты и исходные файлы. Сайт статический, без зависимостей во время выполнения.

Автоматическая проверка в изолированном Chromium подтвердила:

- Четыре процедуры загружают соответствующие изображения и реплики.
- Выбор процедуры сохраняется в URL и восстанавливается после перезагрузки. Неизвестные значения, включая имена свойств прототипа, безопасно возвращают первую процедуру.
- Стрелки, Home и End переключают вкладки с правильным фокусом.
- Добавление процедуры обновляет талон. Все четыре услуги дают 5 400 ₽.
- Пустой выбор даёт 0 ₽ и понятное сообщение. Фокус возвращается к первой процедуре.
- Талон создаётся и копируется с выбранными услугами и правильной суммой.
- Нажатие на маскота меняет реплику.
- Горизонтального переполнения нет при 360, 390, 519, 520, 759, 760, 761, 768, 1024 и 1440 px.
- Режим уменьшенного движения отключает плавные переходы.
- Страница об условиях и данных доступна.
- Ошибок JavaScript и неудачных HTTP-запросов нет.

Ручная визуальная проверка рендеров: 360, 390, 768 и 1440 px, а также полный лист страницы и изображение для ссылки. После первой итерации уменьшен герой, устранены переполнение и склеенный заголовок. После второй перенесена подсказка, чтобы лапа не закрывала текст. Заголовки, цены и кнопки прочитаны в реальном масштабе.

## Telltale

`check_contrast.py http://127.0.0.1:4173 --strict`: 0 ошибок контраста на 390/1440 px при обеих системных настройках темы. Поддерживается одна светлая тема. Четыре отметки для ручной проверки относятся к двум элементам подписи «он просто спросить» в двух системных настройках; подпись и стрелка визуально читаются на оранжевом фоне.

`check_design_tells.py index.html styles.css app.js about.html --json`: все кандидаты рассмотрены.

| Кандидат | Решение |
| --- | --- |
| Знак в бренде | Заменён на SVG после обнаружения подстановки emoji в iOS. |
| Два длинных тире | Сохранены в названии метаданных и русском предложении по правилам языка. |
| Два linear-gradient | Создают только зубчатый край бумажного талона. Перехода цветов и текста на градиенте нет. |
| Три круглых элемента | Печать об уходе со всех сторон и две круглые кнопки. Это отдельные формы, а не скругление всех контейнеров. |
| Два hover-transform | Единственный игровой герой отвечает на наведение. Остальные элементы не прыгают. Уменьшение движения соблюдено. |
| Галочки в CSS и JS | Обозначают состояние настоящих элементов выбора. Реализованы SVG и CSS-границами, без текстовых символов. |
| `Blob` как «sparkle» | Ложное совпадение: стандартный Blob сохраняет талон текстовым файлом. |
| «Empty state» не найден | Пустой талон реализован и проверен; сканер не распознал русскую формулировку. |

Изменение цветовой темы посетителем не предусмотрено. Проект использует локальные шрифты и парные цветовые роли. Проверка интерфейса не выдаётся за аудит реального груминг-бизнеса.

## Исправление иконок на iOS

Текстовые пиктограммы заменены на inline SVG с currentColor: все стрелки, знак бренда, плюс и динамические галочки. Галочка checkbox нарисована CSS-границами. В публичном HTML, JS и CSS не осталось символов пиктограмм, которые iOS может заменить цветными emoji. Версии URL CSS и JS обновлены для обхода старого кеша. Мобильный рендер и оба состояния талона проверены в Chromium; реальное устройство iPhone в этой проверке не использовалось.
