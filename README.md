# Кошачье очко

Шуточный лендинг груминг-салона с двумя характерными котами. Дизайн сделан по [telltale](https://github.com/IgorMitrofanov/telltale-design).

## Локально

Нужен Node.js 22 или новее. Зависимостей нет.

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. `npm run build` проверяет пути и собирает `dist/`.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует `dist/` после push в `main`. В настройках репозитория Pages должен использовать GitHub Actions. Все пути относительные и работают под `/cat-ass/`.

## Поведение

- Примерочная из четырёх процедур меняет иллюстрацию и реплику. Выбор отражается в URL.
- Кот реагирует на нажатия.
- Талон суммирует услуги, копируется или скачивается как текст. Ничего не отправляется.
- Поддерживаются клавиатура, уменьшение движения и мобильные экраны.

Это демонстрационный проект: без реального бронирования, оплат и сбора личных данных. Шрифты размещены локально; лицензии находятся в `assets/fonts/`. Исходные PNG сохранены в `assets/`, в релиз попадают оптимизированные WebP. Изображения созданы ИИ по предоставленным референсам.
